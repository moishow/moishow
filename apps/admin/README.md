# 모이쇼 운영 웹

실제 `/api/v1/operator/cases`와 상세·처리 API를 사용하는 React/TypeScript/Vite 클라이언트다. API 서버와 같은 출처의 reverse proxy로 `/api`를 연결하거나 서버에서 허용한 출처를 사용한다. 브라우저에 저장된 가짜 큐나 완료 상태는 없다.

`npm ci`, `npm run build`, `npm run dev`. 개발 API 주소는 `VITE_API_BASE`로 지정한다. 기존 소셜+SMS 가입 서비스 세션을 입력한다. 운영자 권한은 `platform_operator`의 오프라인 관리 SQL로만 부여하며 클라이언트 설정으로 만들 수 없다. 토큰은 React 메모리에만 존재한다.

금융 상태 변경 권한은 없다. 정정·인계·콘텐츠 조치는 담당자에게 보내는 추적 가능한 요청이며 실제 송금/입금이나 다른 서비스 콘텐츠 삭제를 완료한 것으로 표시하지 않는다.
`npm run dev`는 `/api`를 기본 `http://127.0.0.1:8080` 서버로 프록시한다. 다른 서버 포트는 `VITE_PROXY_TARGET`으로 지정한다. 배포 시에도 동일 출처 `/api` reverse proxy를 구성한다.

추가 권한: 목록에서 ‘담당하고 열기’를 누르면 현재 버전으로 claim 후 해당 사건만 엽니다. 이미 담당자가 있는 사건은 상세 조회 권한을 서버에서 검사합니다. 연결된 금융 이의도 정확하게 할당된 한 건의 별도 API로만 조회하고 전체 정산 접근은 부여하지 않습니다. 신고 증빙은 원래 신고된 단일 글/댓글/메시지 원문이며 대화방 전체를 열지 않습니다.
보호된 금융 증빙(file:UUID)은 같은 서비스 세션으로 파일 API를 조회한 뒤 임시 Blob URL로 열고 내려받습니다. 사건·세션 변경·로그아웃에 URL을 폐기하고, 이전 세션에서 시작한 늦은 응답은 버립니다. URL에 bearer 토큰을 넣지 않습니다.

`npm run build`는 strict TypeScript 검사 후 Vite 번들을 만든다. 실제 API/권한 동작과 TypeScript 빌드 성공은 구분한다.
