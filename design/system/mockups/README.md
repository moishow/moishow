# 목업 이미지

정책 v1.0의 HTML 57개를 실제 브라우저에서 전체 페이지 캡처한 JPEG다. AI가 상상해 그린 화면이 아니라 `screen_v1/`의 렌더 결과다. [갤러리](index.html)에서 HTML과 비교한다.

원본: screen-catalog.json + prototype-render.js + tokens.css + components.css. 화면 변경 후 JPEG도 다시 캡처한다. 캡처/시각 검증일: 기본2026-10-22, BANK는2026-10-23 CODEF 예금주→1원 코드 흐름으로 원본 브라우저 전체 JPEG를 재캡처했다. 다른 화면을 같은 날 다시 캡처한 것으로 표시하지 않는다.
