# 모임 도메인 — 참여·정산·적립금
> 2026-10-22 · 정책 P02~P08 · [정책 정본](../../product/POLICY.md)

## 관계와 역할
모임 ⊃ 정모/번개 ⊃ 차수. 정모=모임장/관리자, 번개=부원 누구나. 정산 담당은 주최 행위 또는 실제 인계 완료로 정하며 모임 운영 권한과 분리한다.

## 가입·운영
모임 미리보기는 이름·선택 소개/지역/분류/대표이미지·실제 활성 인원을 표시하며 내부 콘텐츠는 공개하지 않는다. 대표이미지는 개설/변경자가 소유한 개인 POST 사진을 명시 선택한 경우만 소개 범위로 재공개한다. 모임 미리보기 → 즉시 가입(닉네임 입력) 또는 승인제 폼 → 가입. 일반 초대는 승인 생략, 강퇴 이력은 초대여도 승인 필요, 블랙리스트는 가입·공개 번개·마감 후 합류 차단. 이력은 해당 모임에만 적용한다. 승인제 대기 신청은 관리자 승인 또는 사유를 남긴 거절이 가능하며 신청·결정 이력과 메모는 본인/현재 해당 모임 관리자만 본다. 거절은 블랙리스트가 아니며 재신청은 기존 가입 우선순위를 따른다. 모임장 승계·관리자 지정·공지·초대·블랙리스트를 모임 운영에서 처리한다.

## 차수 신청·선납
차수 선택 → 정원 내 즉시 확정/초과 대기. 차수별 마감→해당 확정자 회비 요청. 사후 정산은 선납 요청 없이 종료 후 실제 지출을 요청한다. 미납 자동 참여 취소 없음. 마감 후 합류는 본인 요청→주최자 승인→해당자 요청만 생성한다. 현재 활성 주최자는 아직 확정된 적 없는 합류 요청만 사유를 남겨 거절할 수 있다. 요청 메모/결정 이력은 본인과 해당 주최자만 보며 정산 인계 담당자에게 이벤트 운영 권한을 주지 않는다. 거절은 취소비·노쇼·점수가 아니며 동일 차수 재신청은 기존 중복 신청 제한을 따른다. 주최자 임의 선정·탈락/세션 재오픈을 기본으로 삼지 않는다.

## 취소·변경
차수별 고지 취소 비용=노쇼 비용. 미설정은 0원. 납부자는 비용 차감 환불, 미납자는 비용만 요청. 주최자 취소/날짜 변경 불참은 전액 환불. 비용 변경은 재동의, 거부자는 무료 취소, 미응답 참여 유지·동의 대기·새 비용 미적용.

## 납부·정산
외부 송금→납부 신고→담당자 실제 확인. 부분 납부 인정·잔여 요청. 실입금 시각 미확인은 지연 판정 보류. 지출 항목명/금액/차수 필수·증빙 선택. 받은 취소 비용만 차수 지출에 보태 참석자 분담을 줄인다. 차수별 계산 뒤 이벤트 개인별 합산/기지급 환불 반영, 순차액만 추가 요청/환불한다.

## 0명·초과·지연 수금
0명도 정산 허용, 나누기만 생략. 고지 취소 비용을 넘는 부족분은 주최자 부담으로 표시한다. 취소 비용이 지출보다 많으면 납부 비율 환불, 원 단위 나머지만 적립. 나중에 받은 비용은 담당자가 추가 환불 또는 적립을 선택·알림한다.

## 계산 마감·정정·이의
종료 후 72시간 최초 등록. 미납/이의가 남아도 계산 마감 가능, 업무 기록과 요청 유지. 원본 보존·정정 기록 추가, 납부액 대비 순차액 재계산. 이의는 납부와 병행하며 필요 시 모임장→운영자로 상향한다. 실제 처리 담당자만 분쟁 증빙을 열람한다.

## 인계·해산
모임 탈퇴 후 주최 책임 유지. 인수자 수락→내역/금액→외부 송금→실입금 확인→권한 이전, 0원은 내역/0원 확인. 기존 주최자에게 돌려줄 선지출 의무도 인계한다. 지출은 개인 자금/모인 돈·실제 지급자를 구분하고 자기 부담·외부 납부·실제 반환을 중복 계산하지 않는다. 보관금에서 본인 선지출을 회수할 때는 명시적 비현금 회수 기록을 남긴다. 송금 뒤 명세가 바뀌어도 실수령 사실은 보존하며 재수락 전 권한은 옮기지 않는다. 계정 삭제는 직접 업무 완료 또는 인계 완료 후 가능. 적립금 계좌 담당은 모임장/관리자 중 1명이며 사용 권한은 모임장/관리자만. 실제 입출금 확인 후 잔액 반영한다. 해산 잔액은 모임장 귀속 정리·확인 후 0원으로 만든다. 담당자 유지·계산 마감 시 미납/환불/이의가 남아도 해산 가능, 기록과 의무는 유지한다.

## 인수 기준
JOIN/EVENT/ROUND/JOIN_LATE/PAY/COLLECT/EXPENSE/SETTLE/REFUND/DISPUTE/CORRECTION/HANDOVER/RESERVE/DISSOLVE. 모든 금액은 원화 정수, 참가자 분담+비용 수령+주최 부담과 지출/환불이 보존되는 예제로 검증한다. 모임장 역할만으로 정산 인수를 자동 완료하지 않는다.
