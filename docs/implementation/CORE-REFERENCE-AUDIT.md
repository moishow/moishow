# 참고 코어 PR17 병합 대조

사용자 확정 Spring Boot/Java25/Gradle과 이슈11의 원화 산술 검증을 함께 유지한다. Node는 참고 예제와 정적 설계 검증만 담당한다. Java CI를 제거하거나 Node 운영 서버를 추가하지 않는다.

원 이슈의 설계·계획은 금액 누적도 안전 정수 범위 이내여야 한다고 규정했다. 서로 다른 사용자의 확정 입금/환불 합계 MAX_SAFE_INTEGER+1이 거절되지 않는 실패 테스트를 확인한 뒤 전체 ledger 합계에도 sumMoney 검증을 추가했다. 확인 전 신고는 실제 수금 합계에 포함하지 않는다. 기존 입력 불변성·ID 중복·비례 환불·원 단위 잔여·금액 보존 예제도 함께 검증한다.

최신 develop을 일반 병합하여 workflow 충돌을 Java25/Gradle build와 Node 참고 테스트/정적 링크 검사 양쪽을 유지하도록 해결했다. 기존 브랜치 이력을 재작성하지 않는다. 참고 코어는 지출 자금 출처/개인 선지출 회수/실제 은행 거래 상태를 모델링하지 않으며, 해당 동작의 구현 근거는 Spring 금융 API와 정책 정본이다.
